# Open WebUI Computer

:::info Recommended setup
Open WebUI Computer is being gradually deprecated. For new setups, use [Open WebUI](/getting-started) with [Open Terminal](/features/open-terminal). These Computer guides remain available for existing installations.
:::

Open WebUI Computer (`cptr`) provides browser access to a machine's files, editor, terminal, git, and AI tools.

## Recommended path

Use **Open WebUI with Open Terminal** for agent workflows. Open WebUI provides the chat interface, models, knowledge, and access controls; Open Terminal adds a workspace for files, shell commands, code execution, and previews.

- [Get started with Open WebUI](/getting-started)
- [Install Open Terminal](/features/open-terminal/setup/installation)
- [Connect Open Terminal to Open WebUI](/features/open-terminal/setup/connecting)
