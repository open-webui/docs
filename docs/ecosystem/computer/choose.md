# Computer, Open WebUI, or Open Terminal?

:::info Recommended setup
Open WebUI Computer is being gradually deprecated. For new setups, use [Open WebUI](/getting-started) with [Open Terminal](/features/open-terminal). These Computer guides remain available for existing installations.
:::

**Open WebUI with Open Terminal is the recommended setup.** Open WebUI provides models, chats, knowledge, users, and permissions. Open Terminal adds files, shell commands, code execution, running processes, and previews so agents can complete work from chat.

- [Get started with Open WebUI](/getting-started).
- [Install Open Terminal](/features/open-terminal/setup/installation) and [connect it to Open WebUI](/features/open-terminal/setup/connecting).
- For managed, per-user workspaces, see [Terminals](/features/open-terminal/terminals/).
- To use a coding agent through Open WebUI, see [coding agents](/features/open-terminal/coding-agents).

## Existing Computer installations

Computer serves a machine's files, editor, terminal, git, and AI tools through a browser. Existing users can refer to the [gateway integration](/ecosystem/computer/automate/open-webui), [data and backups](/ecosystem/computer/operate/data-and-backups), and [security model](/ecosystem/computer/phone-and-remote/security).

Open WebUI with Open Terminal is a separate setup. Back up your Computer data before changing an existing installation.
