Open WebUI provides a comprehensive set of chat features designed to enhance your interactions with AI models. This page provides an overview of the key chat capabilities, with links to dedicated pages for more detailed information.

## Core Chat Features

![A new chat with the model selector and prompt suggestions](/images/features/chat/new-chat-placeholder.png)

![A response rendering LaTeX, a table and a mermaid diagram](/images/features/chat/chat-rich-answer.png)

![The same response continued, with a rendered mermaid diagram and a task list](/images/features/chat/chat-rich-answer-2.png)

![A response with a syntax-highlighted code block](/images/features/chat/chat-code-answer.png)

- **[Folders & Projects](./conversation-organization.md)**: Transform folders into powerful project workspaces with [a default model](./conversation-organization.md#default-model), custom system prompts and attached knowledge bases. Each folder has a [page](./conversation-organization.md#the-folder-page) that shows its chats as a list or a board with statuses, tags and filters.

- **[URL Parameters](./url-params.md)**: Configure chat sessions through URL parameters, enabling quick setup of models, tools, and other features.

- **[Chat Parameters](./chat-params.md)**: Control system prompts and advanced parameters at different levels (per-chat, per-account or per-model), fill placeholders in a shared system prompt with chat or user variables and pick [model controls](/features/workspace/models#using-model-controls-in-chat).

- **[Autocomplete](./autocomplete.md)**: AI-powered text prediction that helps you write prompts faster using a task model.

- **[Chat Sharing](./chatshare.md)**: Share conversations locally or via the Open WebUI Community platform with controllable privacy settings. With [Allow replies](./chatshare.md#allowing-replies), the people you share a chat with can write into the same chat.

- **Response Auto-Scroll**: The view follows a response down the page as it is generated. Turn it off with **Response Auto-Scroll** in **Settings > Interface** to keep the scroll position where you put it, which is useful when you want to read earlier parts of a long answer while the rest is still streaming.

- **Default Upload Mode**: How a file you attach in a chat is handled before you touch anything. **Settings > Interface > File > Default Upload Mode** switches between **Using Focused Retrieval**, the default, where the file is chunked and searched by relevance, and **Using Entire Document**, where its whole content goes into the conversation. It sets the starting point for each new attachment; you can still change an individual file's mode by clicking it after it is attached. See [Retrieval Modes](/features/workspace/knowledge#retrieval-modes) for what the two modes mean.

- **Reference Chats**: Attach another conversation to the current one, so the model can work from what was said there. Pick it from **+ > Add Context > Reference Chats**, which lists your own chats, or drag a chat out of the sidebar and drop it on the message input, which also works for a chat that is not yours. The conversation goes in whole, as plain text, with no chunking and no vector search. Any chat you are allowed to read can be attached, including one [shared with you](./chatshare.md#using-a-shared-chat-as-context) and one sitting in a [folder shared with you](./conversation-organization.md#sharing-folders).

- **Fork a Chat**: Branch a conversation into an independent copy from any assistant response. The **Fork chat** action on a message copies the history from the start of the conversation up to that point into a new chat titled `<original title> (fork)`, so you can take a different direction without touching the original. A fork of your own chat keeps its folder, pin, tags and chat variables. Shared and read-only chats can be forked too; see [Cloning or Forking a Shared Chat](/features/chat-conversations/chat-features/chatshare#cloning-or-forking-a-shared-chat). Forking requires the [Chat Import](/features/authentication-access/rbac/permissions#3-chat-permissions) permission (`chat.import`, allowed by default; admins always pass). Without it the **Fork chat** action is not shown on a message at all. Forking is also unavailable while a response is still streaming, and in a temporary chat, which is never stored.

- **Chat Overview**: A map of the whole conversation in a full-screen window. Open it with **Overview** in the **+** menu of the [tab bar](#tabs-side-panel), listed as soon as the chat has a message in it. A message where older messages were summarized by context compaction carries a **Context compacted** tag on the map.

- **Message Times**: The time on a reply is when it finished, so a long answer carries a later time than the prompt above it. Rest the pointer on a time to see the full date.

- **[History & Search](./history-search.mdx)**: Navigate and search your previous conversations, or allow models to search them autonomously via native tools.

- **Sidebar Hover Previews**: Resting the pointer on a chat in the sidebar opens a small preview of its most recent messages, scrolled to the end, so you can identify a conversation without opening it. Its header shows the number of turns. Only one preview is shown at a time, and moving to another row replaces it. Turn it off with **Chat Hover Previews** in **Settings > Interface > Chat** if you want a quieter sidebar, are sharing your screen or are on a connection slow enough that the previews lag. Previews need a pointer, so they do not appear on a touchscreen.

- **Swipe the Sidebar**: On a phone or tablet, swipe right to open the sidebar and left to close it. On a phone, swipe left across the conversation to open the side panel, and right to close it.

- **[Visualizations](./visualizations.md)**: Models draw interactive charts, diagrams and calculators inline in the chat.

- **[Temporal Awareness](./temporal-awareness.mdx)**: How models understand time and date, including native tools for precise time calculations.

- **[Voice Mode](./voice-mode.mdx)**: Start a hands-free voice conversation with your model using the **Voice mode** button, either through the configured speech engines or as a [Realtime call](/features/chat-conversations/chat-features/voice-mode#realtime-calls) with an OpenAI-compatible realtime voice model. The overlay includes a mute/unmute toggle to temporarily silence your microphone without ending the session, useful in noisy or public environments.

- **[Reasoning & Thinking Models](./reasoning-models.mdx)**: Specialized support for models that generate internal chains of thought using thinking tags.

- **[Follow-Up Prompts](./follow-up-prompts.md)**: Suggested follow-up messages, requests or questions, after each model response.

- **[Automations](./automations.mdx)**: Schedule prompts to run automatically (hourly/daily/weekly/monthly/custom RRULE) and manage recurring runs, optionally into a [folder](./automations.mdx#folders).

- **[Task Management](./task-management.mdx)**: Let agentic models keep a structured task/todo list in chat for multi-step workflows and transparent progress tracking.

- **[Sub-agents](./subagents.mdx)**: Let a model delegate focused work to parallel sub-agents that run with the same tools, and report back.

- **[Timers](./timers.mdx)**: One-shot timers that send a prompt back into the chat when they fire, so a model can pick something up later.

- **[Comments](./comments.mdx)**: Discuss chats, notes and workspace items with the people who can see them, including comments on a selected passage.

- **[Notifications](./notifications.mdx)**: Per-user webhook targets that notify you when a chat finishes or fails, a channel message arrives, or a calendar alert triggers, plus a `notify` tool the model can call.

- **[Keyboard Shortcuts](./keyboard-shortcuts.mdx)**: Rebindable shortcuts for the common actions, managed in **Settings > Keyboard**.
- **Expand the Message Box**: As soon as your prompt runs onto a second line, a button appears in the top right of the message box. It opens **Input**, a full-height editor that shows the whole prompt at once, with the same rich text and formatting toolbar behaviour you have set for the message box. What you write there goes into the message box as you type, so close the editor with the **✕** in its header, `Esc` or a click outside and the text is sitting in the message box ready to send. A single long line that only wraps does not bring the button out.

- **The + Menu**: The **+** button in the message input holds attachments and the per-chat switches: **Tools**, **Skills**, toggleable filters, **Web Search**, **Image** and **Code Interpreter**. Turn on **Show Input Selections** in **Settings > Interface**, in the **Input** section, to show what you selected there as chips beside the **+** button.

- **Compare Text**: **Compare text** in the chat input's **+** menu, or the `/compare` command, opens your current prompt next to an empty **Proposed revision** pane. Paste a revised version there, for example one a model wrote, and click **Compare** to see the two side by side with the changes marked. The same view opens from **Compare revision** in the [skill](/features/workspace/skills#supporting-files) and [prompt](/features/workspace/prompts#creating-a-prompt) editors and on the [model editor's](/features/workspace/models#editor-layout) system prompt.

- **Controls Hidden by the Admin**: An admin can hide single chat controls, such as **Fork chat** or **Attach Files**, under [Visible controls](/features/administration/interface-defaults#hiding-controls). The feature behind a hidden control keeps working.

- **Skill Mentions**: Use `$` in the chat input to mention and activate [Skills](/features/workspace/skills) on-the-fly, injecting their instructions into the conversation.

- **Chat Input Commands**: Typing a trigger character in the chat input opens a suggestion menu:

  | Trigger | Offers |
  |---|---|
  | `/` | Built-in commands (below), plus your [Prompts](/features/workspace/prompts) and [Skills](/features/workspace/skills) |
  | `@` | Models to switch to, plus attachable context: folders, knowledge bases, files from knowledge bases, files from the chat's terminal, and web or YouTube URLs |
  | `#` | Attach folders, knowledge bases, files from knowledge bases, or a web or YouTube URL. See [Attaching knowledge and notes](/features/workspace/knowledge#attaching-knowledge-and-notes) |
  | `$` | Mention and activate skills |
  | `:` | Emoji |

- **Built-in Slash Commands**: these act on the chat or the interface rather than being sent to the model:

  | Command | What it does |
  |---|---|
  | `/compact` | Compacts the conversation now, without waiting for it to cross the threshold. Only offered when [Context Compaction](/troubleshooting/context-window#the-built-in-option-context-compaction) is enabled, and not while a response is generating. A **Context compacted** line marks where older messages were summarized; click it to read the summary. A skipped run says why: the chat is too short, empty or compaction is disabled. |
  | `/status` | Opens a status panel for the chat showing **Context usage**, **Queued messages**, **Tasks** currently running, and the **Chat ID**. |
  | `/fork` | Copies the conversation up to the current message into a new chat, so you can branch off without disturbing the original. |
  | `/side` | Opens a [side chat](#tabs-side-panel) on the current conversation. `/btw` does the same. Text after the command becomes its first message. |
  | `/comments` | Opens the chat's [Comments](./comments.mdx) tab. Offered in a saved chat when comments are turned on. |
  | `/model` | On its own, reports which model the chat is on, listing all of them in a multi-model chat. Followed by a model id, `/model gpt-5.1` for example, it switches the chat to that model. |
  | `/settings` | Opens the Settings dialog. |
  | `/compare` | Opens **Compare text** for the current prompt, the same as the entry in the **+** menu. See **Compare Text** above. |
  | `/skills:create` | Turns the conversation into a reusable [skill](/features/workspace/skills#from-a-chat-with-skillscreate), saved privately to your Skills workspace. Offered once the chat has content and you hold the [Skills Access](/features/authentication-access/rbac/permissions#1-workspace-permissions) permission; the model needs built-in tools with the **Skills** category switched on. Anything you type after it steers what the skill covers. |
  | `/temporary` | Turns temporary chat on or off for the chat you are about to start. The menu entry shows the current state beside it, **On** or **Off**. |



- **Writing & Content Blocks**: Responses from models that include colon-fence blocks (e.g., `:::writing`, `:::code_execution`, `:::search_results`) are automatically rendered as formatted content in a styled container with a copy button. This is commonly used by newer OpenAI models to distinguish different types of output (prose, code results, search results) from the main response text.

  Each block is headed by its type (**Writing**, **Code Execution**), or by its `subject` when the model puts attributes in braces on the opening line, as in `:::writing{variant="email" subject="Short question"}`.

- **Structured Response Editing**: Clicking the edit icon on an assistant response that contains tool calls, reasoning blocks or code-interpreter output opens a structured editor with a collapsible field for each output item and a **JSON** toggle for the underlying [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) payload. Plain text-only responses keep the original textarea.

## Tabs Side Panel

The **Tabs** button (split panel icon) in the top bar opens the tabs. On a large screen the workspace is always full width and the chat is its first tab, which shows the chat title and its actions menu and cannot be closed. On a small screen the tabs open as a panel next to the chat.

The **+** menu opens most of these tabs and also holds **Overview**, the Chat Overview map described above. The panel holds these tabs when they apply: **Files** for the [Open Terminal](/features/open-terminal) or [Code Interpreter](./code-execution/python.md) files, **Artifacts**, **Preview** for embeds and opened citations, **Voice** for a running [voice call](./voice-mode.mdx) and **Comments** for a saved chat with [comments](./comments.mdx) turned on.

**New Chat** in the **+** menu, the **New Chat Tab** [shortcut](./keyboard-shortcuts.mdx#tab-shortcuts), or `/side` in the chat input opens a chat tab that starts from the current conversation, so you can ask something on the side without adding to the chat. Each use opens another numbered tab, so you can keep several open. It needs the [Allow Side Chat](/features/authentication-access/rbac/permissions#3-chat-permissions) permission, and `/side` also needs exactly one selected model. A side chat has the same message input, commands and features as the main chat. It starts with the model's default tools and features and uses the main chat's terminal, which it cannot change.

A side chat is saved when you send its first message. It is a branch of the parent chat with its own title and tags, listed in the chat list and kept in the parent's folder. The **Temporary Chat** toggle in the side chat, shown to users with [Allow Temporary Chat](/features/authentication-access/rbac/permissions#3-chat-permissions), makes it temporary instead: its messages disappear when you close the tab. Users with [Enforce Temporary Chat](/features/authentication-access/rbac/permissions#3-chat-permissions) always get temporary side chats.

Drag a chat from the sidebar onto the chat area to open it as a chat tab. This needs the **Allow Side Chat** permission and is not available while **Enforce Temporary Chat** and **Allow Temporary Chat** are both on.

Pages from the sidebar and the user menu open as tabs beside the chat: [Notes](/features/notes), [Channels](/features/channels), [Workspace](/features/workspace), [Automations](./automations.mdx), [Calendar](/features/calendar), the Playground and Home. Pinned models open as chat tabs. Drag one from the sidebar onto the chat area to place it in a pane. **New Chat** in the sidebar, including the one in a sidebar folder, keeps the open tabs. The **New Chat** button in the top bar on mobile and the temporary chat shortcut close them. Double-click the chat's tab to rename the chat.


With a terminal selected, the **+** menu adds **Files**, **New File** and **New Terminal** tabs, and **Browser** and **Desktop** on terminals that support them, see [The Browser tab](/features/open-terminal/use-cases/web-development#the-browser-tab).

On a large screen the **Split screen** button splits the workspace into panes, or merges them again. You can also drag a tab or a chat from the sidebar to the edge of a pane to split the view side by side or stacked.


Tabs have [keyboard shortcuts](./keyboard-shortcuts.mdx#tab-shortcuts) for opening, closing and switching them.
