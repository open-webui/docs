# Keyboard Shortcuts

Open WebUI ships with keyboard shortcuts for the things you do constantly, and most of them can be **rebound to keys you prefer**. Shortcuts are per user and stored with your settings.

Manage them in **Settings > Keyboard**. Each configurable shortcut can be reassigned individually, or left unassigned, and a **Reset Defaults** button restores **all** of them at once. There is no per-shortcut reset.

## Turning Shortcuts Off

An **Enable Keyboard Shortcuts** toggle at the top of **Settings > Keyboard** switches all of them off at once. It is on by default.

Turn it off when Open WebUI's shortcuts collide with ones your browser or operating system already uses, `Cmd+Shift+C` for the browser inspector being a common example. While it is off, the configurable shortcuts below do not fire and the key combinations pass through to the browser or OS untouched, dictation included, and the small hotkey hints stop appearing in the interface.

Nothing locks you out: the **Settings > Keyboard** tab keeps working while shortcuts are disabled, so you can rebind them or switch them back on at any time. The chat input triggers (`/`, `@`, `#`), `Tab` to accept an autocomplete suggestion, and `Esc` to stop a response or close a dialog are unaffected, since they are not global shortcuts.

`Cmd` below means the `Ctrl` key on Windows and Linux. On macOS it means the `Command` key specifically: `Ctrl` is treated as its own modifier there and does not stand in for `Cmd`, so `Ctrl+K` will not open search on a Mac, only `Cmd+K` will.

## Configurable Shortcuts

These eighteen can be rebound:

| Action | Default |
|---|---|
| New chat | `Cmd+Shift+O` |
| New temporary chat | `Cmd+Shift+'` |
| Delete chat | `Cmd+Shift+Backspace` |
| Open model selector | `Cmd+Shift+M` |
| Toggle dictation | `Cmd+Shift+L` |
| Navigate to previous chat | *(unassigned)* |
| Navigate to next chat | *(unassigned)* |
| Search | `Cmd+K` |
| Open settings | `Cmd+.` |
| Show shortcuts | `Cmd+/` |
| Toggle sidebar | `Cmd+Shift+S` |
| Toggle controls | *(unassigned)* |
| Close modal | `Escape` |
| Focus input | `Shift+Escape` |
| Generate message pair | `Cmd+Shift+Enter` |
| Regenerate response | `Cmd+R` |
| Copy last code block | `Cmd+Shift+;` |
| Copy last response | `Cmd+Shift+C` |

Anything not listed here is fixed and cannot be reassigned.

Three of them ship **unassigned** and do nothing until you give them keys in **Settings > Keyboard**. **Navigate to previous / next chat** step through the sidebar chat list in order, moving to the chat above or below the one you have open, and start at the top of the list if the current chat is not in it. **Toggle controls** opens and closes the chat controls panel. They are left unbound so they cannot collide with an existing binding on arrival — pick keys that suit you.

:::info Changes in this release
Shortcuts used to be a fixed list shown in a modal. They are now rebindable and live in **Settings > Keyboard**; the separate shortcuts modal is gone.

One default changed: **Delete chat** is now `Cmd+Shift+Backspace` only. It previously also responded to `Delete`.
:::

## Chat Input Triggers

Distinct from shortcuts, typing one of these characters in the chat input opens a suggestion menu. See [Chat Features](/features/chat-conversations/chat-features/) for the full list.

| Trigger | Offers |
|---|---|
| `/` | Commands, prompts and skills |
| `@` | Models, knowledge, files, folders and URLs |
| `#` | Knowledge and files |
| `$` | Skills |
| `:` | Emoji |

The `/` menu includes a **Model** entry that opens the model picker with its search box focused, so you can change model without leaving the keyboard or binding anything. Typing `/model` followed by a model id switches straight to it.
