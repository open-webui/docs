# Fikra API

Fikra API is an OpenAI-compatible inference service serving open models such as DeepSeek, GLM, Kimi and Qwen behind one endpoint. Usage is billed per token from a prepaid wallet, with M-Pesa, MTN MoMo, Airtel Money and card payments accepted. New accounts start with a $1 signup credit.

## Get a Fikra API key

1. Sign up at [fikraapi.co.ke](https://fikraapi.co.ke/).
2. Confirm the $1 signup credit in your dashboard.
3. Create an API key under API Keys.
4. Check the [model catalog](https://fikraapi.co.ke/models) for model ids and live pricing.

## Connect Open WebUI

1. Open **Settings** > **Connections**.
2. Click **Manage OpenAI API Connections** under OpenAI API.
3. Click **Add Connection**.
4. Set the base URL to `https://api.fikraapi.co.ke/v1` and paste your Fikra API key.
5. Save. The model list loads from the endpoint.

Model ids such as `deepseek-v4.1-flash`, `glm-5.3-flash` and `kimi-k3` work as-is.
