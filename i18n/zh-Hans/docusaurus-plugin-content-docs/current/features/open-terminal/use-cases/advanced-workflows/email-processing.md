# 处理文件夹中的电子邮件

放入一批 `.eml` 文件，即可获得包含行动事项和截止日期的结构化电子表格。

> **你：** $电子邮件处理器 <br/>
> 检查 /project-emails 文件夹，提取所有行动事项和截止日期。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 列出文件夹中的所有 `.eml` 文件
2. 读取每封邮件：标头（发件人、收件人、主题、日期）和正文
3. 识别行动事项、截止日期、已作出的决定和待解决问题
4. 创建具有结构化列的 CSV
5. 标记逾期事项
6. 撰写最关键邮件的摘要

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: email-processor
description: 读取 .eml 电子邮件文件并提取行动事项、截止日期和关键决定
---

## 电子邮件处理

当被要求处理电子邮件文件时：

1. **列出指定目录中的所有 .eml 文件**
2. **对于每封邮件，提取**：
   - 标头：From、To、CC、Date、Subject
   - 正文：优先使用纯文本，否则去除 HTML 标签作为后备
   - 附件文件名（如果有）
3. **分析每份正文中的**：
   - 行动事项（分配给某人的任务）
   - 截止日期或到期日
   - 已作出的决定
   - 需要回答的问题
4. **创建 CSV**，包含以下列：日期、发件人、主题、行动事项、截止日期、优先级
5. **按日期排序**并标记所有逾期事项
6. **撰写摘要**，突出显示最关键的 5 个事项

保留原始邮件上下文，以便追溯发现。
```
