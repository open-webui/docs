# 批量处理图像

调整文件夹中图像的大小、添加水印、转换格式或生成缩略图。

> **你：** $图像处理器 <br/>
> 我的产品照片在 /photos 中。将它们调整为 800x800、添加水印并制作缩略图。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 使用 PIL/Pillow 处理所有图像（已预装）
2. 创建带水印的全尺寸版本
3. 按请求的尺寸创建缩略图
4. 生成缩略图拼图（所有缩略图的网格）
5. 报告文件数量和节省的空间

![文件浏览器中处理后的图像和缩略图](/images/open-terminal-image-processing-outputs.png)

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: image-processor
description: 批量处理图像——调整大小、添加水印、转换格式和生成缩略图
---

## 图像处理

处理图像时：

1. **先检查**：统计文件数量、检查格式、记录总大小
2. **先处理一个文件作为测试**：在处理其余文件之前展示结果
3. **使用 Pillow（PIL）**：
   - 调整大小时保持宽高比（使用 thumbnail 或 fit）
   - 水印：右下角的半透明文本
   - 格式转换：处理 PNG→JPEG 时的 RGBA→RGB
4. **将输出组织**到清晰的子目录中（processed/、thumbnails/ 等）
5. **生成摘要**：已处理的文件、处理前后的大小
6. **对于大批次**，报告进度：“已处理 25/50……”

批量处理前，始终先预览第一个结果。
```
