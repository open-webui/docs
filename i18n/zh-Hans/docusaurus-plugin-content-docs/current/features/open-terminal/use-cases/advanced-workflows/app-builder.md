# 构建完整的应用程序

描述你的需求，即可获得一个包含前端、后端和数据库的可运行应用。

> **你：** $应用构建器 <br/>
> 为我构建一个库存跟踪器。我需要能够添加包含名称、数量和价格的产品。显示总价值和低库存提醒。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 设计数据库架构
2. 构建带有 CRUD 端点的 Python API（Flask）
3. 创建精致的前端，包含仪表板、图表和搜索
4. 填充示例数据
5. 启动服务器并测试每个端点
6. 可从[浏览器标签页](../web-development.md#the-browser-tab)的**端口（Ports）**列表中打开正在运行的应用

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: app-builder
description: 构建包含前端、后端和数据库的完整 Web 应用程序
---

## 全栈应用程序构建器

构建 Web 应用时：

1. **明确需求**：需要管理哪些数据？UI 应显示什么？
2. **先设计数据库**：使用 SQLite 并采用合理的架构
3. **使用 Flask 或 FastAPI 构建 API**：CRUD、搜索、筛选、错误处理
4. **构建精致的前端**：
   - 现代 CSS（不要只做骨架，要让它看起来可用于演示）
   - 包含关键指标和图表（Chart.js）的仪表板
   - 支持搜索的响应式表格
   - 用于数据录入的表单
5. **填充贴近实际的示例数据**，让演示效果更好
6. **启动服务器**并使用 curl 测试每个端点
7. **验证完整流程**：创建、读取、更新、删除、搜索

构建的成果应足够精致，可用于演示，而不只是线框图。
```
