# 研究并总结任意主题

向 AI 提出一个问题，它会从网络收集信息、加以整理，并撰写结构化的简报。

> **你：** $Research Assistant <br/>
> 固态电池目前的发展状况如何？主要参与者有哪些？商业化的时间表是什么？

## AI 会执行哪些操作 {#what-the-ai-does}

1. 使用 `curl` 从相关科技新闻网站、公司页面和文章获取内容
2. 解析 HTML，提取有用的文本
3. 交叉核对多个来源中的事实
4. 创建结构化的 Markdown 简报，包含章节、来源引用和对比表格
5. 同时保存为 Markdown 和 PDF

## 技能内容 {#skill-content}

将以下内容复制到 **工作区 → 技能 → 创建（Workspace → Skills → Create）**：

```markdown
---
name: research-assistant
description: 从网络研究主题并创建结构化简报文档
---

## 研究助手

当收到研究某个主题的请求时：

1. **先制定计划**：确定 3-5 个调查角度
2. **收集信息**：使用 curl 从权威来源获取内容。使用 beautifulsoup4 解析 HTML 并提取文本
3. **记录每个来源的以下信息**：
   - 关键论点和数据点
   - 发布日期
   - 来源的权威性/可靠性
4. **整理成文档**：
   - 执行摘要（3 句话）
   - 按主题组织的研究发现
   - 在有助于理解时使用对比表格
   - 包含 URL 的来源列表
5. **标出冲突**：注明来源之间存在分歧之处
6. **保存**为 Markdown，也可选择保存为 PDF

明确区分来源中的事实与你自己的分析。
```
