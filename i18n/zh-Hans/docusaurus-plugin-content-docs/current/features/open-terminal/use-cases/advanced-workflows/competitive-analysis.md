# 竞争分析

抓取竞争对手的定价页面并构建对比结果。

> **你：** $竞争分析员 <br/>
> 检查这 5 个竞争对手的网站，并将他们的定价方案与我们的方案进行比较。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 获取每个竞争对手的定价页面
2. 解析 HTML，提取方案名称、价格和功能列表
3. 规范化定价（月度与年度）
4. 构建对比电子表格并突出显示关键差异
5. 撰写战略观察结论

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: competitive-analyst
description: 抓取竞争对手网站并构建定价/功能对比表
---

## 竞争分析

分析竞争对手时：

1. **使用 curl** 获取页面。设置 user-agent 标头并处理重定向
2. **使用 beautifulsoup4 解析 HTML** 以提取：
   - 方案名称和价格
   - 功能列表
   - 促销优惠（免费试用、折扣）
3. **规范化数据**：必要时将年度价格换算为月度价格
4. **创建对比 CSV**，以竞争对手为列、功能为行
5. **撰写战略观察结论**：我们在哪些方面更便宜/更昂贵？竞争对手有哪些我们没有的功能？
6. **注明日期**（定价经常变化）

将发现呈现为可付诸行动的洞察，而不只是原始数据。
```
