# 对比文档的两个版本

上传合同或提案的两个版本，即可获得清晰的更改摘要。

> **你：** $文档对比器 <br/>
> *（上传 contract_v1.docx 和 contract_v2.docx）* <br/>
> 对比这两个版本。重点关注付款条款和责任方面的变化。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 读取两个文档（Open Terminal 原生支持 .docx）
2. 计算段落/句子级别的文本差异
3. 对更改进行分类：仅格式、轻微措辞、实质性更改
4. 突出显示你要求关注的具体方面（付款条款、责任）
5. 创建对比报告，并排显示关键更改

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: document-comparator
description: 对比两个文档版本并突出显示有意义的更改
---

## 文档对比

当被要求对比文档时：

1. **读取两个版本**并提取全文
2. **使用 Python 的 difflib 计算**段落或句子级别的差异
3. **对每项更改进行分类**：
   - 仅格式（空格、大小写）
   - 轻微措辞（同义词、澄清）
   - 实质性更改（数字、日期、条款、义务、新增/删除的条款）
4. **如果用户提到关注的方面**（例如“付款条款”），在两个文档中搜索这些部分并进行有针对性的对比
5. **创建报告**，其中包含：
   - 按类别划分的更改摘要
   - 带有完整上下文的实质性更改
   - 关键部分的并排视图
6. **保存**为 Markdown 和 HTML

始终标记影响财务条款、法律义务或截止日期的更改。
```
