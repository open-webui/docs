# 将原始数据转化为精美报告

上传杂乱的数据，AI 会清理和分析数据、构建图表，并生成可下载的 PDF 报告。

> **你：** $数据报告生成器 <br/>
> *（将 `survey_responses.csv` 拖放到文件浏览器中）* <br/>
> 分析这份调查数据，并为我们的团队会议创建一份报告。

## AI 会执行哪些操作 {#what-the-ai-does}

1. 读取 CSV 并识别数据质量问题
2. 清理数据（修正格式、删除重复项、处理缺失值）
3. 计算统计数据：回复率、平均值、分布
4. 生成图表（条形图、饼图、趋势线）
5. 将所有内容组合成格式化的 PDF，其中包含标题页、摘要、图表和数据表
6. 将 PDF 保存到文件浏览器以供下载

## 技能内容 {#skill-content}

将以下内容复制到**工作区 → 技能 → 创建**：

```markdown
---
name: data-report-generator
description: 分析数据文件并创建包含图表和摘要的专业 PDF 报告
---

## 数据分析与报告

当被要求分析数据时：

1. **先剖析数据**：读取文件并报告行数、列类型、缺失值和重复项
2. **清理数据**：统一格式、填充或标记缺失值、删除完全重复的项。将清理后的版本另存为单独的文件
3. **找出数据中的故事**：识别分布、异常值、相关性和趋势。重点介绍最有趣的 3-5 项发现
4. **创建图表**：使用 matplotlib 和一致的调色板。清晰标记所有坐标轴。将每个图表保存为 /charts 目录中的 PNG
5. **构建 PDF**：使用 reportlab 或 weasyprint 创建包含以下内容的报告：
   - 带有报告名称和日期的标题页
   - 执行摘要（3-5 个要点）
   - 每项主要发现各设一节，包含图表和解读
   - 附录中的数据表
6. **将所有内容保存**到 /reports 目录

始终用通俗易懂的语言解释发现，不要使用统计学术语。
```
