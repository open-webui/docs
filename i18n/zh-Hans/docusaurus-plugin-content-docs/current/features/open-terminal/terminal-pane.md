# 终端窗格

[文件浏览器](./file-browser.md)下方是 AI 正在运行内容的实时视图：AI 启动的每条命令都有自己的选项卡。若需要自己的交互式 shell，请从**选项卡**的 **+** 菜单中选择**新建终端**；可以并排打开多个终端。

AI 运行命令后，终端窗格便会出现，最初折叠为一条标有**会话**的横条。有命令正在运行时，横条会显示命令数量。点击横条或其右侧的箭头即可展开。

---

## 每条命令一个选项卡 {#a-tab-per-command}

AI 运行的每条命令都会显示为独立的选项卡，以命令本身作为标签。标签前的圆点表示状态：

| 圆点 | 含义 |
| :--- | :--- |
| 绿色 | 仍在运行 |
| 灰色 | 已结束（无论退出码为何），或终端已无法识别该命令 |

将鼠标悬停在选项卡上，会以文字显示相同的信息，包括退出码。选择选项卡即可实时查看该命令的输出。如果命令产生的输出超过窗格的保留量，开头会显示一行提示，说明较早的输出已被省略。

已结束命令的选项卡带有 **✕**，可用于关闭选项卡。正在运行的命令无法关闭，这是有意设计的：该选项卡是显示其输出的唯一位置。关闭后的选项卡不会再次出现，但终端仍会列出对应命令。

## Shell 选项卡的命名 {#naming-of-shell-tabs}

**新建终端**选项卡以正在运行的程序设置的标题命名，因此运行编辑器、开发服务器或智能体的选项卡会显示相应名称，而空闲 shell 会显示自己的标题。名称旁的图标表示选项卡中正在运行的程序。Claude Code、Codex、Python、Node.js、npm、git、Docker 和其他一些常见程序有专属图标，其他程序则使用普通终端图标。图标会跟随 Open Terminal 报告的前台运行程序变化，该功能适用于类 Unix 系统。请保持 Open Terminal 为最新版本，参见[更新](/features/open-terminal/setup/updating)。

## 使用须知 {#good-to-know}

:::tip 这是观察窗口，而不是控制开关
关闭选项卡或折叠整个窗格都不会改变 AI 正在执行的操作。这些只是终端的视图，而不是控制终端的开关。
:::

:::info 只有当前查看的选项卡会发送输出
命令列表会实时流传输；窗格打开时，屏幕上当前选项卡的输出也会实时流传输。后台选项卡中的命令不会向浏览器发送输出，直到你切换到该选项卡。
:::

:::info 触摸屏上的附加按键
在手机或平板电脑上，**新建终端**选项卡中的终端下方会显示一行附加按键，包括 **Tab**、**Esc**、**Ctrl**、方向键和 `| ~ / - _`，用于弥补触摸键盘缺少的按键。**Ctrl** 会作用于你接下来输入或点击的按键。
:::

:::info 一次一个终端
与文件浏览器一样，该窗格跟随聊天中选定的终端。切换终端也会切换当前查看的实例。
:::

## 适用于自托管终端服务器 {#for-self-hosted-terminal-servers}

Open WebUI 通过 WebSocket 代理交互式终端，该连接携带 `X-User-Id` 和 `X-Session-Id` 标头，分别指明已登录用户和终端所属的聊天，与 HTTP 代理相同。按用户划分会话的终端服务器会在两种连接上看到相同的身份。

Open WebUI 根据已通过身份验证的会话设置 `X-User-Id`，因此浏览器无法自行选择该值。`X-Session-Id` 是浏览器报告的聊天 ID。
