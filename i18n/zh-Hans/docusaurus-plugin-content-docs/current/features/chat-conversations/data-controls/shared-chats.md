Open WebUI 提供集中式仪表板，用于管理你分享过的每个聊天对话。此功能让用户能够审查共享内容，并在需要时快速撤销访问权限。

:::info
本页介绍已共享聊天的**管理仪表板**。有关如何共享聊天的信息，请参阅[聊天共享](/features/chat-conversations/chat-features/chatshare)。
:::

## 访问管理仪表板 {#accessing-the-management-dashboard}

1. 点击侧边栏左下角的**个人资料名称**或头像。
2. 从菜单中选择**设置**。
3. 进入**数据控制**标签页。
4. 找到**已共享聊天**所在行，点击**管理**按钮。

## 仪表板功能 {#dashboard-features}

**已共享聊天**弹窗为你分享过的聊天提供统一界面：

- **集中列表**：查看所有具有有效分享链接的对话。
- **搜索与筛选**：按标题快速查找特定的已共享聊天。
- **高级排序**：按以下方式整理共享历史记录：
  - **更新时间**（默认）
  - **标题**
- **复制链接**：使用任意条目旁的**剪贴板图标**，立即将分享 URL 复制到剪贴板。
- **撤销访问（取消共享）**：使用**取消共享图标**（带斜线的链接图标）停用分享链接。
    - :::warning
      撤销访问会立即使链接失效。任何尝试访问该 URL 的人都会被重定向到首页；如果已退出登录，则会被重定向到登录页面。对于通过[允许回复](/features/chat-conversations/chat-features/chatshare#allowing-replies)共享的聊天，接收分享的人也将无法访问聊天本身。此操作不可撤销，但你可以在主界面中再次共享该聊天，生成一个*新的*唯一链接。
      :::
- **分页**：列表每次加载 60 个条目，滚动到底部时会自动获取下一批。点击底部的**取消共享所有聊天**按钮并确认后，可一次性撤销所有链接。

## 常见问题 {#faq}

**问：取消共享聊天会删除原始对话吗？**

**答：**不会。取消共享只会删除公开链接。你的原始聊天历史记录会完整保留。

**问：可以在这里管理我分享到社区平台的聊天吗？**

**答：**不可以。此仪表板管理的是在你的本地实例上生成的链接。有关共享到社区的内容，请参阅[删除已共享聊天](/features/chat-conversations/chat-features/chatshare#deleting-shared-chats)。

**问：如果删除原始聊天，分享链接会怎样？**

**答：**删除聊天也会立即使所有关联的分享链接失效并将其删除，包括聊天随所属文件夹一起删除的情况。
