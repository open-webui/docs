Open WebUI 允许你归档对话，在保留对话以供日后查阅的同时，让侧边栏保持整洁。通过**已归档聊天**仪表板，你可以集中管理所有已归档的对话。

## 访问已归档聊天 {#accessing-archived-chats}

1. 点击侧边栏左下角的**个人资料名称**或头像。
2. 从菜单中选择**设置**。
3. 在**数据**下打开**已归档聊天**标签页。

已归档聊天以前位于**数据控制**标签页的**管理**按钮下，现在在同一**数据**组中拥有独立的标签页。

## 仪表板功能 {#dashboard-features}

**已归档聊天**视图提供以下工具来管理已归档的对话：

- **搜索**：使用搜索栏按标题快速查找已归档聊天。
- **恢复**：将已归档聊天恢复到主侧边栏。归档单个聊天会将其从所在文件夹中移除，并停止仍在生成的回复；恢复聊天不会将其放回该文件夹。
- **删除**：从你的账户中永久删除已归档聊天。

## 批量操作 {#bulk-operations}

打开**设置 > 数据控制**（位于**数据**下）进行批量操作：

- **归档所有聊天**：一次性将你当前的所有对话移至归档。这适用于定期清理。
- **删除所有聊天**：永久删除你拥有的全部聊天，包括已归档聊天和文件夹中的聊天，以及你创建的每个分享链接。即使以管理员身份登录，操作范围也仅限于你自己的账户。上传到这些聊天的文件和在其中生成的图像不会被删除；请在**管理文件**中删除它们。
  - :::warning
    此操作不可撤销，且不能按时间或文件夹筛选。如需保留部分聊天，请逐个删除其余聊天。
    :::

:::info 删除需要聊天删除权限

只有拥有**允许删除聊天**权限的用户才会看到已归档聊天上的**删除**和**删除所有聊天**。没有此权限时，这两个选项都不会出现，因此不存在点击后才被拒绝的按钮；归档和**取消全部归档**仍可正常使用。该权限默认开启，管理员始终不受限制。请参阅[权限](/features/authentication-access/rbac/permissions#3-chat-permissions)。

:::

:::info 管理员隐藏归档功能

管理员可以在[可见控件](/features/administration/interface-defaults#hiding-controls)下隐藏**归档**，这也会同时隐藏取消归档功能。已归档聊天仍可在此处打开和删除。

:::

## 常见问题 {#faq}

**问：可以在已归档聊天中搜索内容吗？**

**答：**可以。归档仪表板本身按聊天标题搜索。当你添加 `archived:true` 筛选条件时，搜索窗口（`Cmd+K` / `Ctrl+K`）和聊天输入框 **+** 菜单中的**引用聊天**选择器也会检索已归档聊天中的消息，例如 `archived:true quarterly report`。无需恢复聊天即可搜索其中的内容。请参阅[历史记录与搜索](/features/chat-conversations/chat-features/history-search#filter-prefixes)。

**问：可归档的聊天数量有限制吗？**

**答：**没有硬性限制。可扩展性取决于你的数据库配置。

**问：已归档聊天仍占用存储空间吗？**

**答：**是的。已归档聊天仍保留在你的数据库中。若要释放空间，必须将其永久删除。
