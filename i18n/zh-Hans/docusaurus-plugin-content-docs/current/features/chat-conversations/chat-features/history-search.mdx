# 历史记录与搜索

Open WebUI 提供强大的系统，用于管理和浏览此前的对话。无论你是在查找上个月的某段代码，还是尝试整理数百个聊天，历史记录和搜索功能都能帮助你快速找到所需数据。

## 聊天历史侧边栏 {#chat-history-sidebar}

你的所有对话都会自动保存在**侧边栏**中。

![搜索聊天历史](/images/features/chat/history-search.png)

*   **持久保存**：聊天保存在内部数据库（`webui.db`）中，并可在你的所有设备上使用。
*   **组织方式**：聊天按时间段分组（今天、昨天、过去 7 天等）。
*   **悬停预览**：将指针停留在聊天上会打开一张小卡片，显示其最近消息，让你无需打开即可区分不同对话。卡片标题会显示聊天的轮次数量，统计你的消息和当前分支上的回复。包含多个模型回复的聊天，每轮只显示当前分支上的一个回复。如果你希望侧边栏更简洁、正在共享屏幕，或者所用连接较慢而预览出现延迟，可以在**设置 > 界面 > 聊天（Settings > Interface > Chat）**中通过**聊天悬停预览（Chat Hover Previews）**关闭它。预览需要指针，因此不会出现在触摸屏上。
*   **未读指示器**：有新活动的聊天会在侧边栏显示未读圆点，直到你打开它们。聊天的三点菜单提供**标记为未读（Mark as unread）**，可恢复圆点；文件夹菜单和**聊天（Chats）**部分标题自己的菜单都提供**全部标记为已读（Mark all as read）**，可一次清除一个文件夹或整个聊天列表的未读状态。
*   **重命名**：标题由任务模型自动生成，但你可以点击侧边栏中标题旁的铅笔图标，手动重命名任何聊天。打开聊天后，标题旁菜单中的**重命名（Rename）**具有相同作用，字段旁的**生成（Generate）**（星芒）按钮会根据对话撰写新标题。新聊天会在你发送第一条消息后立即请求标题，此时回复仍在生成，因此停止该回复或回复失败都不会让聊天一直没有标题。如果标题请求本身失败，例如无法连接任务模型，聊天会保留**新聊天（New Chat）**名称，后续消息不会再次尝试；请使用**生成（Generate）**为其命名。开启自动标题后，重新生成第一条回复，或编辑并重新发送第一条消息，都会在该回复完成后写入新标题并替换当前标题，包括你手动输入的标题。自动标题的写入不计为活动，因此不会仅因命名就将聊天重新推到列表顶部或再次标记为未读。你可以在**设置 > 界面（Settings > Interface）**中通过**标题自动生成（Title Auto-Generation）**为自己关闭自动标题。只有管理员在**设置 > 界面（Settings > Interface）**（管理员区域）中开启**标题生成（Title Generation）**时，此开关才会显示；开关隐藏期间，你保存的选择仍会保留。
*   **归档**：你可以**归档（Archive）**聊天，将其从主列表移除而不删除。除非使用 `archived:true` 搜索，否则已归档聊天不会出现在搜索窗口中；仍可在**设置 > 已归档聊天（Settings > Archived Chats）**下浏览。管理员可以在**设置 > 界面（Settings > Interface）**（管理员区域）的**可见控件（Visible controls）**下隐藏**归档（Archive）**；有关具体隐藏内容，请参阅[已归档聊天](/features/chat-conversations/data-controls/archived-chats)。
*   **选择多个聊天**：按住 Shift 点击一个聊天即可开始选择。这会选中从你上次点击的聊天到此次按住 Shift 点击的聊天之间的所有聊天。随后，每个聊天都会显示复选框，普通点击即可添加或移除聊天。继续按住 Shift 点击，会从同一个起始聊天扩展范围。侧边栏底部的栏会显示已选择数量，并提供按钮以一次性**归档（Archive）**或**删除（Delete）**全部所选聊天，或**清除选择（Clear selection）**。删除前会要求确认，删除按钮仅在拥有[允许聊天删除（Allow Chat Delete）](/features/authentication-access/rbac/permissions#3-chat-permissions)权限时显示。按 `Escape` 也可以清除选择。属于其他人的聊天，例如共享文件夹中其他人的聊天，无法选中。如果部分聊天操作失败，它们会保持选中，方便你重试。

*   **文件夹未读计数**：文件夹会显示其中未读或等待工具批准的聊天数量，子文件夹也计入其中。请参阅[文件夹与项目](/features/chat-conversations/chat-features/conversation-organization#unread-badge)。

*   **打开和关闭**：侧边栏可以滑入和滑出。打开 Open WebUI 时，聊天只加载一次，不会在每次显示侧边栏时重新加载。因此，隐藏侧边栏再将其打开后，你之前滚动查看的内容仍会保留，而不会回到最新聊天处。

Open WebUI 会按聊天跟踪已读状态，并在你打开对话时更新，因此未读指示器会在不同会话之间保持同步。打开聊天后，其未读标记以及你其他已打开窗口中的文件夹计数都会立即清除。

## 搜索历史记录 {#searching-your-history}

搜索窗口可在一个位置搜索你能够打开的所有内容。

1.  点击侧边栏中的**搜索（Search）**，或按 `Cmd+K` / `Ctrl+K`。
2.  输入查询。窗口会搜索：
    *   **你自己的聊天**，按标题和消息内容匹配
    *   **与你共享的文件夹中的聊天**，包括其子文件夹
    *   按姓名或通过用户组**与你共享的聊天**。以**允许回复（Allow replies）**方式共享的聊天会打开实时对话。任何其他共享聊天都显示为**共享快照（Shared snapshot）**，并打开其分享链接。
    *   你可以访问的**频道和私信中的消息**
    *   你拥有或与你共享的**笔记**
3.  点击结果或按 `Enter` 将其打开。

只有启用频道且你拥有**频道（Channels）**功能权限时，频道消息才会出现。笔记同样要求启用笔记功能并拥有**笔记（Notes）**权限。管理员始终拥有这两项权限。除非使用 `archived:true` 搜索，否则已归档聊天不会包含在内。

查询为空时，窗口会列出**置顶与最近（Pinned & recent）**：先显示你置顶的聊天和笔记，然后按最近活动显示其他所有内容。

### 筛选结果 {#filtering-results}

搜索框旁的按钮用于选择内容类型：**全部（Everything）**、**聊天（Chats）**、**消息（Messages）**或**笔记（Notes）**。旁边的筛选按钮还提供另外两个筛选项：

*   **视图（View）**：**全部（All）**、**由你创建（Created by you）**或**与你共享（Shared with you）**。**与你共享（Shared with you）**会保留由其他人拥有或撰写的条目。
*   **位置（Location）**：**所有位置（Everywhere）**、某个文件夹或某个频道。文件夹包含其子文件夹，且只显示聊天。频道只显示该频道的消息。

活动筛选条件以标签形式显示在搜索框下方。点击标签可将其移除，或使用筛选菜单中的**重置（Reset）**。

你也可以将[筛选前缀](#filter-prefixes)与搜索词一起输入搜索框。`tag:none` 用于查找无标签聊天，标签和文件夹名称中的空格用下划线表示（`folder:client_work`）。任何前缀都会将结果限制为你自己的聊天。输入时，窗口会建议前缀和值；使用方向键选择，再按 `Enter` 或 `Tab` 确认。

### 处理搜索结果 {#working-with-results}

每个结果都会显示标题、所在位置（某个文件夹、**个人聊天（Personal chat）**、**共享聊天（Shared chat）**、某个频道、**个人笔记（Personal note）**或**共享笔记（Shared note）**），以及匹配消息的一小段摘要。仅标题匹配的聊天会显示其最后一条消息。频道消息会将发送者姓名作为标题。查询中的词语会在标题和摘要中高亮。

*   **聊天**会在匹配消息处打开，并切换到包含该消息的分支。
*   **频道消息**会打开频道，并在匹配消息处显示其讨论串。
*   **笔记**会在匹配页面打开，并选中第一个匹配项。

按 `Ctrl/Cmd + Enter` 可在列表旁显示或隐藏所选结果的预览。在宽度至少为 768 px 的屏幕上，预览默认打开；一旦你手动显示或隐藏它，该选择就会应用于所有宽度。预览打开时，单击选择结果，双击打开结果。

**操作（Actions）**菜单可通过其按钮，或在窗口打开时按 `Cmd+K` / `Ctrl+K` 打开，其中包含**打开结果（Open result）**、**显示预览（Show preview）**或**隐藏预览（Hide preview）**、**复制链接（Copy link）**、以查询作为提示词的**开始新对话（Start a new conversation）**，以及以查询作为内容的**创建新笔记（Create a new note）**。

### 查询如何匹配 {#how-queries-are-matched}

在搜索窗口中，由多个单词组成的查询会查找包含所有这些单词的条目，单词顺序不限。单词按空格拆分，最多计算十二个。每个单词可以来自标题或任何消息，不同单词也可以来自不同消息。匹配不区分大小写，并支持子字符串。标题与查询完全相同的条目排在最前，其次是标题包含查询的条目，其余条目按最近活动排序。滚动时会加载更多结果。

聊天输入框 **+** 菜单中的**引用聊天（Reference Chats）**选择器，以及模型的 `search_chats` 工具，会使用不同规则搜索你自己的聊天。由多个单词组成的查询会查找包含所有这些单词的聊天，顺序不限，也不要求它们彼此相邻。每个单词可以来自聊天标题或其任何消息，不同单词可以来自不同消息，因此 `docker healthcheck` 也能找到标题为 "Docker setup"、回复中提到 healthcheck 的聊天。包含与查询完全一致短语的聊天排在最前，然后是其余聊天，每组均按最近更新时间排序。

匹配不区分大小写并支持子字符串，因此 `log` 也能匹配 "login" 和 "backlog"。系统按英文字母和数字从查询中切分单词，因此 `v0.9.1` 会分别搜索 `v0`、`9` 和 `1`。只计算前十二个不同单词。完全使用另一种文字书写的查询，例如中文或俄文，会作为一个精确短语搜索。

### 筛选前缀 {#filter-prefixes}

在搜索窗口和**引用聊天（Reference Chats）**选择器中，可以单独使用筛选前缀，或与查询组合使用，以缩小结果范围：

*   `tag:<name>`：具有指定标签的聊天；`tag:none` 表示无标签聊天
*   `folder:<name>`：某个文件夹中的聊天
*   `pinned:true` 或 `pinned:false`：仅显示置顶聊天，或仅显示未置顶聊天
*   `archived:true` 或 `archived:false`：仅显示已归档聊天，或仅显示未归档聊天
*   `shared:true` 或 `shared:false`：仅显示有分享链接的聊天，或仅显示没有分享链接的聊天

最后三项需要在冒号后使用 `true` 或 `false`。单独输入 `pinned:`、`archived:` 和 `shared:` 时，它们会从查询中丢弃，不会筛选任何内容。在搜索窗口中，后面没有任何内容的 `tag:` 和 `folder:` 也会被丢弃。

搜索窗口会在你输入时建议前缀。当你输入前缀的首字母时，例如输入 `t` 代表 `tag:`，搜索框下方的列表会提供该前缀和简短说明。选择 `tag:` 会列出你的标签，`folder:` 会列出你的文件夹，`pinned:`、`archived:` 和 `shared:` 则提供 `true` 和 `false`。点击建议，或使用方向键配合 `Enter` 或 `Tab` 进行选择。`Escape` 会关闭列表，但保持窗口打开。

搜索窗口中的筛选器只搜索你拥有的聊天。笔记、频道消息和共享快照没有标签、文件夹或归档状态，因此查询包含筛选器时，它们会从结果中排除。

例如，`folder:work meeting notes` 会在 **work** 文件夹中搜索 "meeting notes"。

## 原生对话搜索（Agentic） {#native-conversation-search-agentic}

使用启用了**原生函数调用（Native Function Calling）**的模型时（请参阅[**工具调用中心指南**](/features/extensibility/plugin/tools#tool-calling-modes-default-vs-native)），模型可以自主搜索你的聊天历史。

### 可用的历史记录工具 {#available-history-tools}
- **`search_chats`**：在聊天标题和消息内容中进行文本搜索，使用与**引用聊天（Reference Chats）**选择器相同的匹配规则，并跳过模型当前所在的聊天。返回匹配的聊天 ID 和摘要。
- **`view_chat`**：按 ID 读取并返回特定聊天的消息历史；设置 [`VIEW_CHAT_MAX_CHARS`](/reference/env-configuration#view_chat_max_chars) 后，会截取为最新消息。

启用**内置工具（Builtin Tools）**时，**聊天历史（Chat History）**类别默认开启。要阻止模型使用这些工具搜索以前的聊天，请在**工作区 > 模型（Workspace > Models）**或**管理员面板 > 设置 > 模型（Admin Panel > Settings > Models）**中编辑模型，打开**内置工具（Builtin Tools）**，关闭**聊天历史（Chat History）**并保存。这会从模型的内置工具集中移除上述所有三个工具。

要同时移除内置时钟和日期计算工具，请在同一部分关闭**时间与计算（Time & Calculation）**。该类别默认开启，控制 `get_current_timestamp` 和 `calculate_timestamp`。

### 为什么使用原生工具调用进行搜索？ {#why-use-native-tool-calling-for-search}
这让模型能够利用自己此前的工作。你可以问：*“我上一封电子邮件草稿收到了什么反馈？”*或*“找出我两周前编写的图像处理 Python 脚本。”*

模型会搜索你的历史记录，找到正确的聊天并读取，然后为你提供答案或所需代码，省去手动滚动和复制粘贴的麻烦。

## 数据管理 {#data-management}

*   **导出**：你可以将单个聊天或整个历史记录下载为 **JSON**、**纯文本（.txt）**或 **PDF**。整个历史记录只能导出为 JSON，不支持 Markdown 导出。
*   **导入**：将 JSON 聊天导出文件拖放到侧边栏即可恢复。
*   **删除**：你可以通过侧边栏中聊天的三点菜单或聊天顶部的菜单删除单个聊天，并通过**设置 > 数据控制（Settings > Data Controls）**中的**删除所有聊天（Delete All Chats）**清除整个历史记录。

删除需要[聊天删除权限](/features/authentication-access/rbac/permissions#3-chat-permissions)。管理员移除该权限后，这些删除控件都不会显示，因此你不会再遇到点击后才拒绝操作的删除按钮。归档不受影响，管理员始终不受此限制。
