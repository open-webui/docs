# 键盘快捷键

Open WebUI 为常用操作提供了键盘快捷键，其中大多数都可以**重新绑定为你偏好的按键**。快捷键按用户保存，并与你的设置一同存储。

在 **设置 > 键盘** 中管理快捷键。点击某个快捷键的按键即可录制新按键。`Escape` 或 `Tab` 会取消录制，因此 `Tab` 无法绑定为快捷键。快捷键旁边的小 **x** 可取消分配。**重置默认值**可恢复全部快捷键。

## 关闭快捷键 {#turning-shortcuts-off}

**设置 > 键盘** 顶部的**启用键盘快捷键**开关可以一次性关闭所有快捷键。该开关默认开启。

当 Open WebUI 的快捷键与浏览器或操作系统已经使用的快捷键冲突时，可以将其关闭；一个常见例子是浏览器检查器使用的 `Cmd+Shift+C`。关闭后，下述可配置快捷键不会触发，按键组合会原样传递给浏览器或操作系统（包括听写），界面中的小型热键提示也会停止显示。

要停用单个快捷键，请取消其按键分配。之后，该按键组合会像其他按键一样传递给浏览器。对于默认绑定到浏览器页面刷新按键的**重新生成回复**，这通常是合适的解决方法。

你不必担心无法恢复：禁用快捷键时，**设置 > 键盘** 标签页仍可正常使用，因此随时可以重新绑定或重新启用它们。聊天输入触发符（`/`、`@`、`#`）、用于接受自动补全建议的 `Tab`，以及用于停止回复或关闭对话框的 `Esc` 均不受影响，因为它们不是全局快捷键。

下文中的 `Cmd` 在 Windows 和 Linux 上指 `Ctrl` 键。在 macOS 上，它专指 `Command` 键：`Ctrl` 会被视为独立的修饰键，不能代替 `Cmd`，因此在 Mac 上 `Ctrl+K` 不会打开搜索，只有 `Cmd+K` 可以。

## 可配置快捷键 {#configurable-shortcuts}

以下快捷键可以重新绑定。标签页快捷键单独列在后面的表格中。未出现在这两个表格中的快捷键均为固定快捷键，无法重新分配。

| 操作 | 默认按键 |
|---|---|
| 新建聊天 | `Cmd+Shift+O` |
| 新建临时聊天 | `Cmd+Shift+'` |
| 删除聊天 | `Cmd+Shift+Backspace` |
| 打开模型选择器 | `Cmd+Shift+M` |
| 切换听写 | `Cmd+Shift+L` |
| 导航到上一个聊天 | *（未分配）* |
| 导航到下一个聊天 | *（未分配）* |
| 搜索 | `Cmd+K` |
| 打开设置 | `Cmd+.` |
| 显示快捷键 | `Cmd+/` |
| 切换侧边栏 | `Cmd+Shift+S` |
| 切换控制面板 | *（未分配）* |
| 关闭模态框 | `Escape` |
| 聚焦聊天输入框 | `Shift+Escape` |
| 清除输入选择 | `Escape` |
| 生成消息对 | `Cmd+Shift+Enter` |
| 重新生成回复 | `Cmd+R` |
| 允许工具调用 | `Cmd+Alt+Enter` |
| 拒绝工具调用 | `Cmd+Alt+Backspace` |
| 复制最后一个代码块 | `Cmd+Shift+;` |
| 复制最后一条回复 | `Cmd+Shift+C` |

**生成消息对**会将聊天输入框中的文本添加为你的消息，并为每个所选模型添加一个占位回复，随后你可以手动编辑这些回复。

**清除输入选择**会重置聊天输入框中的选择：移除模型覆盖、取消选择工具和过滤器，并关闭网络搜索、图像生成和代码解释器。它仅在聊天输入框获得焦点时触发。

**关闭模态框**只关闭最上层的对话框，因此在**设置**上方打开的确认框关闭后，**设置**仍会保持打开。`Escape` 始终可以关闭对话框，因此你在此处分配的按键会与 `Escape` 同时生效，而不是取代它。

### 标签页快捷键 {#tab-shortcuts}

这些快捷键位于 **设置 > 键盘** 中的**标签页**下，适用于[工作区标签页](/features/chat-conversations/chat-features/#tabs-side-panel)。如上所述，`Cmd` 在 Mac 以外的系统上表示 `Ctrl`，但**新建终端**在所有系统上都使用 `Ctrl`。当对应标签页不可用时，快捷键不会执行任何操作，例如未选择支持终端的机器时，终端相关快捷键不会生效。

| 操作 | 默认按键 |
|---|---|
| 文件 | `Cmd+Shift+E` |
| 桌面 | `Cmd+Alt+D` |
| 新建聊天标签页 | `Cmd+Alt+O` |
| 评论 | `Cmd+Shift+Y` |
| 新建文件 | `Cmd+Alt+N` |
| 新建终端 | `Ctrl+backtick` |
| 新建浏览器 | `Cmd+Shift+B` |
| 关闭标签页 | `Cmd+W` |
| 下一个标签页 | `Cmd+Shift+]` |
| 上一个标签页 | `Cmd+Shift+[` |
| 切换分屏 | `Cmd+\` |
| 快速打开 | `Cmd+P` |
| 语音笔记 | `Cmd+Alt+M` |

**快速打开**按名称搜索所选机器上的文件。**语音笔记**使用麦克风录音。随后，**转写**会使用 **设置 > 音频**（管理员区域）中设置的语音转文本引擎将录音转换为文本；用户需要具有**允许语音转文本**[权限](/features/authentication-access/rbac/permissions#3-chat-permissions)。使用浏览器自带的引擎时，此功能不可用。**保存**会将包含转写文本和音频链接的 Markdown 笔记以及音频文件写入机器的当前文件夹。

## 固定快捷键 {#fixed-shortcuts}

这些快捷键内置于系统，无法重新绑定。**设置 > 键盘** 会列出前八项供参考。

| 操作 | 按键 | 生效条件 |
|---|---|---|
| 接受自动补全生成内容、跳转到提示词变量 | `Tab` | 聊天输入框已获得焦点 |
| 阻止创建文件 | `Cmd+Shift+V` | 在聊天或频道中粘贴内容，且**将大段文本粘贴为文件**已开启 |
| 从知识库附加文件 | `#` | 在聊天输入框中输入 |
| 添加自定义提示词 | `/` | 在聊天输入框中输入 |
| 与模型对话 | `@` | 在聊天输入框中输入 |
| 停止生成 | `Escape` | 聊天输入框已获得焦点，且正在生成回复 |
| 编辑最后一条消息 | `ArrowUp` | 聊天输入框已获得焦点 |
| 切换静音 | `M` | 语音模式 |
| 搜索此文件夹 | `/` | [文件夹页面](./conversation-organization.md#the-folder-page)显示其聊天，且没有输入框获得焦点 |
| 筛选文件夹中的聊天 | `f` | 同上 |
| 在文件夹中新建聊天 | `c` | 同上，且位于你可以添加聊天的文件夹中 |

**允许工具调用**和**拒绝工具调用**适用于等待批准的回复；只有开启[工具权限](/features/extensibility/plugin/tools#tool-approval)并将聊天设置为先询问，才会出现这种情况。它们作用于最近一个仍在等待的调用，因此有多个待处理调用时，需要逐次按键处理。在其他任何时候，它们都不会执行操作，按键会直接传递。

其中三项默认**未分配**，在 **设置 > 键盘** 中为它们指定按键前不会执行任何操作。**导航到上一个聊天**和**导航到下一个聊天**按顺序遍历侧边栏聊天列表，移动到当前打开聊天的上一项或下一项；如果当前聊天不在列表中，则从列表顶部开始。**切换控制面板**会在小屏幕上打开和关闭[标签页面板](/features/chat-conversations/chat-features/#tabs-side-panel)。这些快捷键默认不绑定按键，以避免启用时与现有绑定冲突；你可以选择适合自己的按键。

**删除聊天**遵循[聊天删除权限](/features/authentication-access/rbac/permissions#3-chat-permissions)。如果管理员已移除该权限，此快捷键不会列在 **设置 > 键盘** 中，也不会执行任何操作，同时侧边栏和菜单中的删除操作也会隐藏。同样，没有**允许临时聊天**权限时，**新建临时聊天**也不会列出。管理员始终不受限制。

## 聊天输入触发符 {#chat-input-triggers}

与快捷键不同，在聊天输入框中输入以下字符之一会打开建议菜单。完整列表请参阅[聊天功能](/features/chat-conversations/chat-features/)。

| 触发符 | 提供的内容 |
|---|---|
| `/` | 命令、提示词和技能 |
| `@` | 模型、知识、文件、文件夹和 URL |
| `#` | 知识和文件 |
| `$` | 技能 |
| `:` | 表情符号 |

`/` 菜单包含**模型**条目，它会打开模型选择器并聚焦搜索框，因此你无需离开键盘或绑定任何快捷键即可更改模型。输入 `/model` 并跟上模型 ID，可以直接切换到该模型。

## 键盘导航 {#keyboard-navigation}

与上述快捷键不同，使用 `Tab` 和 `Shift+Tab` 在界面中逐项导航在任何地方都有效，并且不受**启用键盘快捷键**开关影响。当前到达的位置会显示清晰的轮廓，让你始终知道焦点所在。通常在指针悬停时才出现的按钮（例如消息下方的操作），在你通过 `Tab` 到达时也会显示。

在页面上第一次按 `Tab` 会到达**跳转到主要内容**链接。工具提示也会在键盘焦点到达时显示，并可使用 `Escape` 关闭。通过键盘打开菜单会将焦点移至第一个菜单项，方向键则可在菜单中移动。

屏幕阅读器可以获取图标按钮的名称，并在回复状态、通知和通话状态发生变化时朗读它们。
