# 后续提示词

Open WebUI 可以在每次模型回复后自动建议后续消息。这些建议以可点击的标签形式显示在回复下方，帮助你进一步探索话题，而无需输入新的提示词。

使用内置提示词时，每条建议都会写成你接下来可能发送的消息，可以是一个问题或一项请求，并将最相关的一条排在首位。管理员可以在**设置 > 界面（Settings > Interface）**（管理员区域）中通过**后续消息生成提示词（Follow Up Generation Prompt）**替换它，也可以使用 [`FOLLOW_UP_GENERATION_PROMPT_TEMPLATE`](/reference/env-configuration#follow_up_generation_prompt_template) 进行配置。

使用内置提示词时，任务模型会看到聊天的第一条用户消息，以及当前分支的最后四条消息，其中最后一条就是这些建议所针对的回复。这些消息中，任何超过 1,000 个字符的消息都会截取为 1,000 个字符：保留开头和结尾，并用 `...` 连接。自定义**后续消息生成提示词（Follow Up Generation Prompt）**会收到未经截断的完整分支，而模板中的 `{{MESSAGES}}` 变量决定模型实际看到的内容。例如，`{{MESSAGES:END:6|middletruncate:1000}}` 会传入最后六条消息，并将每条消息缩短至 1,000 个字符。

## 设置 {#settings}

在**设置 > 界面（Settings > Interface）**的**聊天（Chat）**部分配置后续提示词行为：

### 自动生成后续消息 {#follow-up-auto-generation}

**默认：开启**

每次回复后自动生成后续建议。这些建议由[任务模型](/reference/env-configuration#task_model)根据对话上下文生成。

- **开启**：每次模型回复后生成后续提示词
- **关闭**：不生成后续建议

只有当管理员在**设置 > 界面（Settings > Interface）**（管理员区域）中开启**后续消息生成（Follow Up Generation）**时，此开关才会显示。开关隐藏期间，你保存的选择仍会保留，并在管理员重新开启生成后再次生效。无论此开关是否显示，下面两项设置都会保持可见，因为它们也适用于已经保存在聊天中的后续建议。

### 在聊天中保留后续提示词 {#keep-follow-up-prompts-in-chat}

**默认：关闭**

默认情况下，后续提示词只显示在最新消息下方，并在你继续对话后消失。

- **开启**：保留后续提示词，并让聊天历史中的所有消息都持续显示这些提示词
- **关闭**：只有最后一条消息显示后续提示词

:::tip 非常适合知识探索
探索知识库时可以启用此设置。你能看到此前各次回复给出的全部后续建议，从而轻松回顾并探索信息中的其他路径。
:::

### 将后续提示词插入输入框 {#insert-follow-up-prompt-to-input}

**默认：关闭**

控制点击后续提示词时发生的行为。

- **开启**：点击后续提示词会将文本插入输入框，你可以先编辑再发送
- **关闭**：点击后续提示词会立即将其作为下一条消息发送

## 按 Tab 采用建议 {#taking-one-with-tab}

回复完成后，第一条后续建议还会以灰色虚影文本的形式显示在空消息输入框中。按 **Tab** 即可将其写入输入框，然后编辑或发送。输入任何其他内容后，虚影文本就会消失，因此不会妨碍你撰写自己的消息。

只有在输入框为空且最后一条消息是已完成的回复时，虚影文本才会显示；模型再次开始生成时，它会立即消失。回复下方的建议标签不受影响，虚影文本与其中第一条建议相同。

## 重新生成后续建议 {#regenerating-follow-ups}

如果要为特定回复重新生成后续建议，可以使用社区提供的[重新生成后续消息（Regenerate Follow-ups）](https://openwebui.com/posts/9b5ac6d6-dfd6-4cad-bc1d-5518b138f22d)操作按钮。
