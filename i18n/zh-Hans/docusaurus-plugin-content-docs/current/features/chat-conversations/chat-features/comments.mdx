# 评论

评论让用户能够直接在模型、知识库、提示词、技能、工具、笔记或聊天旁边展开讨论。管理员可以在**设置 > 通用（Settings > General）**（管理员区域）中通过**评论（Comments）**启用此功能，也可以使用 [`ENABLE_COMMENTS`](/reference/env-configuration#enable_comments) 环境变量。此功能默认关闭。

## 谁可以评论 {#who-can-comment}

任何能够读取某个条目的人都可以读取其评论并添加自己的评论。评论笔记还需要启用[笔记功能](/features/notes)。临时聊天没有评论。对于直接来自连接且从未使用独立设置保存过的模型，只有管理员可以评论。

## 在哪里查找评论 {#where-to-find-them}

- **聊天**：评论位于**评论（Comments）**[标签页](/features/chat-conversations/chat-features/#tabs-side-panel)，可通过标签栏 **+** 菜单中的**评论（Comments）**打开。
- **笔记**：笔记顶栏中的**评论（Comments）**按钮会在笔记旁边打开评论。
- **模型**：模型选择器中，模型菜单内的**评论（Comments）**。
- **工作区**：每个列表行上的评论按钮以及条目编辑器顶栏中的评论按钮，都会在弹出窗口中打开评论。条目菜单中的**评论（Comments）**会打开同一个弹出窗口，每个列表还会显示评论数量。

## 撰写评论 {#writing-comments}

你可以回复评论、用表情符号回应评论，或通过 `@mention` 提及某人。提及列表只提供能够查看该条目的人，被提及者还会在其[收件箱](./notifications.mdx#inbox)中收到通知。

要评论某段具体文字，请在聊天消息或笔记页面中选中该段文字，然后点击**评论（Comment）**（在可编辑笔记中，点击格式工具栏上的**评论（Comment）**按钮）。该段文字会保持高亮，将鼠标悬停在其上即可预览相关评论。如果文字在此期间发生了变化，请重新选中该段文字。

你可以编辑自己的评论。评论作者、条目所有者或管理员可以删除评论。

删除条目会同时删除其评论。删除用户账户后，其评论会保留文本，但不再显示作者。

API 位于 `/api/v1/comments`。
