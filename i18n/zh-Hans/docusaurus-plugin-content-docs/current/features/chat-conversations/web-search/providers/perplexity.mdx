## Perplexity API {#perplexity-api}

:::info

本教程中的 Perplexity API 使用 Perplexity 自己的模型，而不仅仅是网页搜索 API。如需使用网页搜索 API，请按照另一篇教程操作。

:::

### 设置 {#setup}

1. 前往：`Settings` -> `Web Search`（管理员区域）
2. 开启 `Web Search`
3. 在下拉菜单中将 `Web Search Engine` 设为 `perplexity`
4. 输入从 [Perplexity API 密钥管理](https://www.perplexity.ai/account/api/keys)获取的 Perplexity API 密钥。
5. （可选）设置 **Perplexity 模型（Perplexity Model）**（`PERPLEXITY_MODEL`，默认值为 `sonar`）和 **Perplexity 搜索上下文用量（Perplexity Search Context Usage）**（`PERPLEXITY_SEARCH_CONTEXT_USAGE`，可选 `low`、`medium` 或 `high`，默认值为 `medium`）。回答中的引用会成为搜索结果，标题依次为 `Source 1`、`Source 2` 等，回答文本则作为第一条结果的摘要。
6. 点击保存
