## DDGS（Dux Distributed Global Search） {#ddgs-dux-distributed-global-search}

DDGS 是一个元搜索引擎，可让你通过单一界面搜索多个提供方。

:::info 无需安装，也无需账户
DDGS 随 Open WebUI 一起提供，并在其中运行。无需部署单独的服务、连接容器、配置 URL 或获取 API 密钥。完成以下三个步骤即可完成全部设置。

它通过各搜索提供方的公开页面访问这些提供方，而不是通过付费 API。如果你需要某个提供方的官方 API 及其附带的可靠性和配额，请改用网页搜索引擎列表中该提供方自己的条目，例如 Brave、Google PSE 或 SerpApi；这些条目都需要密钥。
:::

### 设置 {#setup}

1. 在管理员设置中启用**网页搜索**。
2. 选择 **DDGS** 作为**网页搜索引擎**。该条目对应的引擎值是 `duckduckgo`，因此通过环境变量配置时，请设置 `WEB_SEARCH_ENGINE=duckduckgo`。`ddgs` 不会匹配任何引擎。精简版镜像不提供 DDGS，因此该条目在精简版镜像中处于禁用状态。
3. 从下拉菜单中选择所需的 **DDGS 后端**。

#### DDGS 后端选项 {#ddgs-backend-options}
- **自动（随机）**：从可用的提供方中随机选择。
- **Bing**
- **Brave**
- **DuckDuckGo**
- **Google**
- **Grokipedia**
- **Mojeek**
- **Wikipedia**
- **Yahoo**
- **Yandex**

#### 环境变量 {#environment-variable}
你也可以使用 `DDGS_BACKEND` 环境变量配置后端。

```bash
DDGS_BACKEND="google"
```

#### 选择后端 {#choosing-a-backend}

**自动（随机）**是默认选项，也是最可靠的选择。由于每次搜索都会随机选择一个提供方，单个提供方拒绝请求不会导致整个搜索功能停止工作。

固定使用单一后端意味着每次搜索都依赖于该提供方持续响应自动化请求。各提供方对此类请求的处理方式不同，有些提供方不会返回错误，而是返回一个不含结果的页面，因此固定的后端可能不返回任何内容，而其他后端仍能正常工作。同一提供方也可能在正常响应一段时间后开始拒绝请求；与家庭网络连接相比，共享地址或数据中心地址更容易被拒绝。

如果固定的后端搜索不返回任何内容，请先切回自动模式，再更改其他设置。

:::warning 模型提示搜索工具不可用
这通常与搜索引擎无关。只有同时满足以下条件，模型才能使用搜索工具：在管理员设置中启用网页搜索、在该模型的编辑器中为其启用网页搜索、为当前聊天启用网页搜索、用户拥有使用权限，并且模型未设置为 Legacy 函数调用。如果某个模型在自己的编辑器中关闭了网页搜索能力，即使搜索功能在其他地方都完全正常，该模型仍会提示工具不可用。
:::
