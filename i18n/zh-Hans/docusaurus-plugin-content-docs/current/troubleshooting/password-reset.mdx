# 重置管理员密码

以下分步指南介绍如何在 Docker 和本地安装环境中重置管理员密码。

## Docker 部署 {#for-docker-deployments}

### 步骤 1：生成新密码哈希 {#step-1-generate-a-new-password-hash}

为新密码创建 bcrypt 哈希。将 `your-new-password` 替换为要使用的密码：

```bash
htpasswd -bnBC 10 "" your-new-password | tr -d ':\n'
```

:::note

输出会包含一个带特殊字符的 bcrypt 哈希。在步骤 2 的 Docker 命令中使用时，哈希中的所有 `$` 字符都必须进行三重转义（替换为 `\\\`）。

:::

### 步骤 2：在 Docker 中更新密码 {#step-2-update-the-password-in-docker}

将 `HASH` 替换为步骤 1 中生成的 bcrypt 哈希（对所有 `$` 字符进行三重转义），并将 `admin@example.com` 替换为你的管理员邮箱。如需查询管理员邮箱，请使用[备用方法](#alternate-docker-method)的步骤 4。

```bash
docker run --rm -v open-webui:/data alpine/socat EXEC:"bash -c 'apk add sqlite && echo UPDATE auth SET password='\''HASH'\'' WHERE email='\''admin@example.com'\''; | sqlite3 /data/webui.db'", STDIO
```

如果上述命令执行失败，请使用下面的备用方法。

#### Docker 备用方法 {#alternate-docker-method}

由于 `alpine/socat` 镜像不包含 `bash`，上述单行命令在某些环境中可能执行失败。此时请改用以下分步方法：

1. **启动一个挂载了 Open WebUI 数据卷的 Alpine 容器：**

    ```bash
    docker run -it --rm -v open-webui:/data alpine
    ```

2. **安装所需工具：**

    ```sh
    apk add apache2-utils sqlite
    ```

3. **生成 bcrypt 哈希：**

    ```sh
    htpasswd -bnBC 10 "" your-new-password | tr -d ':'
    ```

4. **更新密码：**

    ```sh
    sqlite3 /data/webui.db
    ```

    如果不知道管理员邮箱，请先列出管理员账户：

    ```sql
    SELECT email, role FROM user WHERE role = 'admin';
    ```

    然后更新该邮箱对应的密码：

    ```sql
    UPDATE auth SET password='HASH' WHERE email='admin@example.com';
    -- 邮箱以小写形式存储，因此混合大小写地址会匹配零行，且 sqlite3 不会输出任何内容。请使用 SELECT changes(); 确认。
    -- 退出 sqlite：Ctrl+D
    ```

## 本地安装 {#for-local-installations}

### 步骤 1：生成新密码哈希 {#step-1-generate-a-new-password-hash-1}

```bash
htpasswd -bnBC 10 "" your-new-password | tr -d ':\n'
```

### 步骤 2：更新密码 {#step-2-update-the-password}

进入 `open-webui` 目录。如果不知道管理员邮箱，请先列出管理员账户：

```bash
sqlite3 backend/data/webui.db "SELECT email, role FROM user WHERE role = 'admin';"
```

然后运行：

```bash
sqlite3 backend/data/webui.db "UPDATE auth SET password='HASH' WHERE email='admin@example.com';"
```

将 `HASH` 替换为步骤 1 中生成的 bcrypt 哈希，并将 `admin@example.com` 替换为你的管理员邮箱。

## 重置所有数据 {#resetting-all-data}

如果要**完全重置** Open WebUI，包括所有用户数据、设置和密码，请删除 `webui.db` 文件。

### 步骤 1：找到 `webui.db` {#step-1-locate-webuidb}

如果不确定 `webui.db` 的位置，可以使用 Python shell 查找：

```python
import os
import open_webui

# 显示 Open WebUI 软件包的安装位置
print("Open WebUI is installed at:", open_webui.__file__)

# 构造预期的数据库路径
db_path = os.path.join(os.path.dirname(open_webui.__file__), "data", "webui.db")

if os.path.exists(db_path):
    print("webui.db found at:", db_path)
else:
    print("webui.db not found at:", db_path)
    print("Try: find / -name 'webui.db' 2>/dev/null")
```

### 步骤 2：删除 `webui.db` {#step-2-delete-webuidb}

```bash
rm /path/to/webui.db
```

:::warning

删除 `webui.db` 会移除**所有**已存储的数据：用户账户、设置、聊天历史和密码。仅在需要彻底重新开始时执行此操作。

:::
