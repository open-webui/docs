### 资产来源 {#asset-source}

- 官方品牌资产可在项目仓库中获取
- 始终使用提供的文件，不要手动重新制作资产
- 如果缺少某项资产或需要其他格式，请通过官方项目渠道联系 Open WebUI 团队

## 品牌名称用法 {#brand-name-usage}

官方名称为 **Open WebUI**。

### 正确用法： {#correct-usage}
- Open WebUI（指品牌或产品时）
- open-webui（通常用于仓库或软件包名称）

### 错误变体（请勿使用）： {#incorrect-variations-do-not-use}

- OpenWeb UI
- OpenWebUI
- OpenWeb
- Open Web UI
- openweb-ui
- OpenWeb Ui
- openWebUI
- Open-Web UI
- open web UI
- open-ui
- open-web-ui

指品牌或产品时，始终使用 **Open WebUI**，按所示写法拆分为两个单词并保留大小写。

指仓库、软件包或代码库时，使用小写并带连字符的 **open-webui**。

## 标志与视觉识别 {#logo-and-visual-identity}

- 紧凑的品牌展示位置优先使用 Open WebUI 图标。
- 仅当资产中需要包含品牌名称时，才使用横版标志。
- 按原样使用 Open WebUI 图标和横版标志，不做修改。
- 不得拉伸、裁剪或扭曲图标或标志。
- 不得更改品牌资产颜色或添加效果。
- 在品牌资产周围提供留白，确保其清晰可见。
- 在干净、不杂乱的背景上使用品牌资产，确保可读性。

## 字体排印 {#typography}

- 使用符合 Web 标准、简单易读的字体。
- 在所有 Open WebUI 材料中保持字体大小和样式一致。
- 避免使用降低可读性的装饰性字体。

## 使用规则 {#usage-rules}

- 除非获得明确许可，不得以任何暗示官方认可的方式使用 Open WebUI 标志或名称。
- 不得将 Open WebUI 品牌融入你自己的产品或公司品牌。
- 禁止以任何形式对 Open WebUI 部署进行联合品牌展示，包括在页脚或管理通知中设置独立或从属的组织徽标。间距或大小均不构成例外。允许通过平台内置设置更新模型图标或聊天背景。获准的管理通知和公司链接必须为纯文本，且字号必须严格小于 `text-xs`。有关详情和适用的品牌例外，请参阅[许可证指南](/license/#branding-attribution-and-customization-guidelines-whats-allowed-and-whats-not)。
- 始终维护品牌完整性，并按原样使用资产。

## 联系方式 {#contact}

如有关于使用 Open WebUI 品牌资产的问题，请通过官方仓库或项目沟通渠道联系 Open WebUI 团队。有关组织部署的品牌使用指南，请参阅[部署品牌政策](/license/)。
