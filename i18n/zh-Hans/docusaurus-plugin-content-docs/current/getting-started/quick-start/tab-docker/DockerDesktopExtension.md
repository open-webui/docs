# Docker Desktop 扩展 {#docker-desktop-extension}

Docker 发布了一个 Open WebUI Docker 扩展，使用 Docker Model Runner 进行推理。你可以在这里阅读他们的入门博客：[使用 Open WebUI + Docker Model Runner 运行本地 AI](https://www.docker.com/blog/open-webui-docker-desktop-model-runner/)。

你可以在其 GitHub 仓库中找到该扩展的故障排除步骤：[Open WebUI Docker 扩展 - 故障排除](https://github.com/rw4lll/open-webui-docker-extension?tab=readme-ov-file#troubleshooting)。

虽然该资源能让你轻松体验 Open WebUI，但它并不是官方支持的安装方式，使用过程中可能会遇到意料之外的缺陷或行为。例如，由于该扩展面向单个本地用户设计，你无法在扩展中以不同用户身份登录。如果使用扩展时遇到问题，请在该扩展的 [GitHub 仓库](https://github.com/rw4lll/open-webui-docker-extension)提交问题。
