AI 领域有许多优秀的项目，我们由衷为此感到高兴。工具越多，就有越多的人能以适合自己的方式使用 AI。

经常有人问我们“还有哪些其他选择？”，因此我们整理了这份清单。如果 Open WebUI 不完全适合你的使用场景，这些也是我们愿意毫不犹豫推荐的工具。我们实际使用过它们、与它们共同构建过项目，或者只是认为它们在某些方面做得非常出色。这里列出的所有项目都可以免费开始使用。

## 如何选择 {#how-to-choose}

- **运行本地模型？**从 [Ollama](/alternatives/ollama) 或 [llama.cpp](/alternatives/llama-cpp) 开始，两者都可与 Open WebUI 配合使用
- **想要桌面应用？**[Llama app](/alternatives/llama-cpp#llama-app-local-ai-in-a-few-clicks) 将 llama.cpp 带到 Mac 菜单栏和 Windows 11 系统托盘，支持模型下载和浏览器聊天。[LM Studio](/alternatives/lm-studio) 和 [Jan](/alternatives/jan) 也是出色的独立选择
- **需要文档问答？**[AnythingLLM](/alternatives/anythingllm) 让私有 RAG 变得简单
- **多服务提供方聊天？**[LibreChat](/alternatives/librechat) 可以很好地处理这一需求
- **构建 AI 工作流？**[Dify](/alternatives/dify) 提供可视化工作流设计器
- **想要开箱即用的 AI？**[ChatGPT](/alternatives/chatgpt)、[Claude](/alternatives/claude) 和 [Gemini](/alternatives/gemini) 是世界上出色的 AI 产品：前沿模型、精致界面、快速迭代，几乎不需要设置。它们的模型也可通过 API 在 Open WebUI 中使用。

## 常见问题 {#frequently-asked-questions}

**Open WebUI 免费吗？**
免费。社区版支持不限数量的用户，同时提供企业套餐。

**我可以自托管 Open WebUI 吗？**
可以。Open WebUI 可通过 Docker、Kubernetes、pip 或桌面应用在你自己的基础设施上运行。你的数据保留在自己的硬件上。

**Open WebUI 支持哪些模型？**
Open WebUI 可连接任意与 OpenAI 兼容的 API，并原生集成 Ollama，包括 OpenAI、Anthropic、Google、Azure、AWS Bedrock、llama.cpp、LM Studio 以及数百家其他服务提供方。
